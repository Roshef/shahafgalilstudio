# Shahaf Galil Studio — האתר המלא

32 דפים סטטיים: דף בית, 26 עולמות עבודה, הצהרת אמן, אודות, תערוכות, יומן, פנייה.
פריסה: להעלות את התיקייה כמו-שהיא ל-Vercel (Framework: Other, בלי Build).

## הרצה מקומית
```bash
python3 -m http.server 8000
# http://localhost:8000/index.html
```

## מבנה
```
index.html            בית: פתיח → תערוכה פעילה → תפריט גופי עבודה → הצהרה
works/<key>.html      עולם עבודה: כותרת → דימוי+אובייקטים → רבדים → בנייה → פעולות
statement.html        הצהרת אמן מוקצבת (מילה-מילה, 3 שפות)
about / exhibitions / journal / contact
data/site-data.js     ★ כל התוכן — עריכה כאן בלבד
data/peppers.json     תוכן פלפלים המלא (5 קטגוריות, חולץ מהגרסה הישנה)
build.js              node build.js — מייצר את כל הדפים מחדש
css/site.css · js/    עיצוב והתנהגות
assets/*-hero.svg     דימויי מקום (placeholders)
```

## זרימת עבודה: כל שינוי תוכן
1. לערוך את `data/site-data.js`
2. `node build.js && node build-live.js`
3. commit + push (Vercel מתעדכן אוטומטית)

## מה נשאר לך להשלים (מסומן גם בקוד)

| מה | איפה | איך |
|---|---|---|
| **הצילומים האמיתיים** | `assets/` | להחליף כל `<key>-hero.svg` בקובץ אמיתי (WebP ~2400px, לפי IMAGE_PIPELINE מהחבילה שלך) ולעדכן את הסיומת ב-build.js או לשמור באותו שם |
| **מיקומי אובייקטים** | `site-data.js → hotspots` | המיקומים מוערכים לפי הטקסטים; לכוונן אחוזים אחרי הכנסת הצילומים (`hotspot_helper.py` מהחבילה שלך) |
| **פרטי התערוכה** | `site-data.js → EXHIBITION` | למלא ולהחליף `confirmed: true` — הבלוק בדף הבית מתעדכן לבד |
| **סאבסטאק** | `CONFIG.substackUrl` | כשתפתח — כתובת אחת, וכל כפתורי היומן והפוטר מתחברים אוטומטית |
| **Clarity** | `CONFIG.clarityId` | מזהה מ-clarity.microsoft.com — הסקריפט, באנר הקוקיז ואירועי section_view מופעלים אוטומטית |
| **GA4** | `CONFIG.ga4Id` | אופציונלי; מפעיל דוחות מקורות + section_view |
| **קורות חיים** | `ABOUT.cv` | שורה לכל פריט (תערוכות, השכלה, פרסים) |
| **תרגומים** | טקסטים ללא `ar`/`en` | עברית קיימת לכל 26 העבודות; ערבית+אנגלית מלאות לתריסים, פלפלים ולהצהרה (1–4). כותרות בערבית לעבודות החדשות תורגמו — מומלץ בדיקת דובר |
